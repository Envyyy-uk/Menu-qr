# PODVAL — сторінка меню (без сервера)

Статична сторінка меню для QR-коду на столі. Ні бекенду, ні збірки, ні
залежностей: три файли в `assets/` і каталог у `data/menu.json`. Відкривається
навіть подвійним кліком по `index.html` — з файлової системи, без інтернету.

## Що вміє

- Каталог трьома мовами — українська, English, русский. Мова запамʼятовується
  (`localStorage`) і задається посиланням: `index.html?lang=en`.
- Усі 30 позицій із меню бару: міцне, коктейлі, пиво й безалкогольне, вино й
  ігристе, гарячі напої, кальяни.
- Варіанти з цінами: обʼєми, вид, смак, подача, стиль. Драбинка обʼємів
  (50→300 мл) згорнута під «усі обʼєми», щоб картка лишалася читною.
- Пошук працює трьома мовами одразу: `лайм`, `lime` і `mint` знаходять ті самі
  коктейлі — шукає по назві, опису, складу й варіантах.
- Стрічка розділів угорі підсвічує розділ, який гість зараз читає.
- Друк (`Ctrl+P`) дає чисту двоколонкову картку без панелей.

Назви позицій і варіантів навмисно не перекладені: гість замовляє їх так, як
надруковано в меню й записано в барі.

## Файли

```
index.html            каркас сторінки
assets/styles.css     оформлення: папір, золото, антиква
assets/i18n.js        рядки інтерфейсу (uk / en / ru)
assets/menu-data.js   каталог — згенеровано, руками не правити
assets/app.js         рендер, пошук, мови
data/menu.json        джерело каталогу — правки вносити сюди
tools/build_data.py   data/menu.json → assets/menu-data.js
```

## Як правити меню

1. Змінити позицію, ціну чи переклад у `data/menu.json`.
   Ціни — у пенсах: `1300` це £13.00.
2. Перезібрати каталог:

   ```sh
   python3 tools/build_data.py
   ```

3. Оновити сторінку в браузері.

Рядки інтерфейсу (заголовки, підписи, застереження) живуть окремо — у
`assets/i18n.js`.

## Як опублікувати

Будь-який статичний хостинг. Наприклад, GitHub Pages: Settings → Pages →
Deploy from a branch → гілка й корінь репозиторію. Далі QR-код веде на адресу
сторінки; `?lang=uk` у посиланні відкриє потрібну мову одразу.
